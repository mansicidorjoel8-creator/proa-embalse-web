Formación Integral en IT

A lo largo de la trayectoria escolar, los estudiantes abordan lógica de programación, arquitectura de datos y desarrollo de proyectos reales.

  • Programación orientada a objetos (Python, Java, C++).
  • Desarrollo Web Full-Stack (HTML5, CSS3, JavaScript).
  • Gestión y modelado de Bases de Datos (SQL, MySQL).
  • Sistemas embebidos, IoT y Robótica educativa.
